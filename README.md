# ZAKIA Maroc — site web

React + Vite + Tailwind CSS v4 + Framer Motion + Lucide + Lenis (smooth scroll).

```
npm install
npm run dev      # développement
npm run build    # production (dist/)
```

- `src/data/products.js`, `recipes.js` : contenu du catalogue et des recettes.
- `src/data/site.js` : **coordonnées de contact à compléter** (téléphones, email, adresse) — les champs vides ne sont pas affichés.
- `public/img/products/` : packshots optimisés (WebP), jamais retouchés (seul recadrage/détourage du fond).
- `public/img/food/` : visuels culinaires recadrés depuis les emballages fournis.
- `scripts/images.mjs` : régénère les images depuis les originaux.
